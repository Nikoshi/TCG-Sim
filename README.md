# RESTNETZ

**RESTNETZ** ist ein taktisches Kartenspiel in Entwicklung. Hier kannst du die aktuellen Spielmechaniken ausprobieren und die Regeln kennenlernen.

## Teststation

- **Regelsimulator:** Zwei Fraktionen, drei Infrastrukturknoten und jede Menge Entscheidungen.
- **Tutorial:** Ein geführter Einstieg in die Spielregeln (folgt).

Der Simulator ist derzeit nur mit einem zeitlich begrenzten **Testcode** zugänglich.

> **Frühe Testversion 0.2:** Regeln, Karten und Darstellung können sich noch ändern. Feedback ist willkommen.
